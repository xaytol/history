# History Lab — коллоквиум по истории

Статический тренажёр по материалу из файла «Коллоквиум с ответами»: **119 вопросов и ответов**, случайные карточки, самостоятельная проверка, поиск и фильтры, сохранение прогресса и план подготовки на два дня.

## Что внутри

- **Карточки:** колода по умолчанию перемешана; можно открыть ответ, отметить «Знаю» или «Повторить», сохранить вопрос в избранное.
- **Воспроизведение:** сначала сформулируй ответ сам, затем сверься с ответом из конспекта и отметь результат.
- **Все вопросы:** поиск по формулировке и ответу, фильтр по теме и статусу, раскрытие ответов.
- **Прогресс:** отметки и чек-лист плана сохраняются в localStorage браузера.
- **План на 2 дня:** активное вспоминание, повторение ошибок, смешивание тем и короткая устная самопроверка.
- **Без сервера и сборки:** обычные HTML, CSS и JavaScript.

## Развернуть через GitHub Pages

1. Открой **Settings → Pages** в этом репозитории.
2. В разделе **Build and deployment** выбери источник **GitHub Actions**.
3. Открой вкладку **Actions** и проверь успешный запуск **Deploy static site to GitHub Pages**.
4. После успешного деплоя сайт будет доступен по адресу **https://xaytol.github.io/history/**. Его можно также найти в **Settings → Pages**.

Воркфлоу находится в `.github/workflows/pages.yml` и запускается при каждом push в ветку `main`.

## Структура

- `index.html` — страница тренажёра.
- `styles.css` — оформление для компьютера и телефона.
- `app.js` — карточки, случайный порядок, поиск, фильтры и локальный прогресс.
- `data/questions_part*.json` — весь набор вопросов и ответов. В видимых формулировках удалена начальная нумерация.

## Об исходном документе

Формулировки и ответы перенесены из пользовательского DOCX. Исторические сведения не переписывались и не дополнялись: возможные неточности исходника могут сохраниться. В исходном документе номер 26 использован дважды, поэтому в наборе **119 пар «вопрос — ответ»**.
