# History Lab — тест № 3 по истории России

Статический тренажёр для подготовки к тесту по истории России XVII–XVIII веков: **4 самостоятельных варианта по 30 вопросов (120 вопросов всего)**.

## Как пользоваться

- Выбери **вариант 1, 2, 3 или 4** в переключателе над рабочей областью.
- В разделе **Карточки** вопросы идут по исходному порядку. Можно перемешать выбранный вариант, открыть ответ и отметить карточку как «Знаю» или «Повторить».
- В разделе **Решать вопросы** отвечай по одному вопросу, записывай ответ своими словами, затем сверяйся с ключом.
- В разделе **Список вопросов** доступны все 30 вопросов выбранного варианта, поиск по формулировкам и фильтр по прогрессу.
- Отметки «Знаю», «Повторить», избранное и чек-лист подготовки сохраняются в localStorage браузера. Прогресс одного варианта не смешивается с прогрессом остальных.

## Распределение материалов

| Вариант | Источник в сообщении | Вопросов |
|---|---|---:|
| 1 | «Тест № 3: вопросы и краткие ответы» (номер варианта не был указан) | 30 |
| 2 | «Тест № 3 (Вариант 2)» | 30 |
| 3 | «Вопросы и краткие ответы по истории России (XVIII век)» (номер варианта не был указан) | 30 |
| 4 | «Тест № 3. Вариант 4» | 30 |

Во втором исходном блоке не было вопроса № 22. Чтобы сохранить четыре равных набора, в варианте 1 на этом месте добавлен дополнительный тематический вопрос об учреждении Петербургской академии наук. В интерфейсе это явно отмечено.

## Проверка исторических ответов

Ответы проверены и уточнены там, где исходные формулировки были спорными или неверными. В частности:

- встреча Петра I с Исааком Ньютоном не подтверждена документами; это обозначено как недоказанный факт;
- Патрик Гордон не мог давать советы во время Прутского похода 1711 года: он умер в 1699 году;
- по Табели о рангах VIII гражданский/придворный класс давал потомственное дворянство, а для военных оно полагалось с XIV класса — первого офицерского;
- Анна Иоанновна отменила указ о единонаследии, но не указ о престолонаследии 1722 года; в 1731 году она подтвердила действие порядка назначения наследника;
- первый морской форт у Котлина назывался Кроншлот; Кронштадт — более позднее название укреплённого города;
- уточнены командные роли Меншикова в Померании и участие Румянцева в сражении при Гросс-Егерсдорфе.

Формулировки кратких учебных вопросов местами нормализованы для точности. Если в вашем преподавательском билете используются другие слова, ориентируйтесь на формулировку преподавателя, сохраняя исторически верный смысл.

## Развернуть через GitHub Pages

1. Открой **Settings → Pages** в этом репозитории.
2. В разделе **Build and deployment** выбери источник **GitHub Actions**.
3. Проверь успешный запуск workflow **Deploy static site to GitHub Pages** во вкладке **Actions**.
4. Сайт будет доступен по адресу **https://xaytol.github.io/history/**. Ссылка также отображается в **Settings → Pages**.

## Структура

- \`index.html\` — страница тренажёра.
- \`styles.css\` — оформление для компьютера и телефона.
- \`app.js\` — переключение вариантов, карточки, самопроверка, поиск и локальный прогресс.
- \`data/variants.json\` — 4 варианта по 30 вопросов и ответов.
- \`data/questions.json\`, \`data/questions_part*.json\` — первоначальный набор карточек, оставленный в репозитории как исходные материалы; новая версия тренажёра использует \`data/variants.json\`.

## Технологии

Обычные HTML, CSS и JavaScript. Сборка и сервер не требуются.
