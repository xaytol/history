# History Lab — карточки по истории России

Тренажёр для подготовки к контрольной работе по истории России XVII–XVIII веков. В репозитории сохранены только вопросы из присланных материалов: **119 карточек в четырёх отдельных вариантах**.

## Варианты

| Вариант | Вопросов |
|---|---:|
| 1 | 29 |
| 2 | 30 |
| 3 | 30 |
| 4 | 30 |
| **Всего** | **119** |

В исходном первом списке отсутствовал вопрос № 22. Он не заменялся и не дополнялся новым вопросом: нумерация после пропуска сохранена.

## Возможности

- Выбор одного из четырёх вариантов.
- Два режима порядка карточек: **«Случайно»** и **«По порядку»**; выбор режима сохраняется.
- Кнопка **«Все варианты вместе»** объединяет 119 исходных карточек.
- Открытие и скрытие ответа на карточке.
- Отдельно сохраняются карточки, которые уже прорешаны, и карточки, отмеченные как выученные.
- После завершения колоды можно пройти её заново или повторить только невыученные карточки.
- Режимы «Случайно» и «По порядку»; выбранный режим сохраняется.
- Кнопка «Все варианты вместе» объединяет 119 карточек.
- Отметки «Знаю», «Повторить» и «В избранное».
- Отдельный режим самопроверки и полный список вопросов выбранного варианта.
- Вкладка «Вероятность» оценивает шансы на оценку по числу выученных карточек и отдельно показывает прогноз для каждого варианта.
- Прогресс и настройки сохраняются локально в браузере.
- Светлая и тёмная темы с запоминанием выбора.

## Вероятность оценки

В расчёте используется предположение, что на контрольной с одинаковой вероятностью выпадает один из четырёх вариантов. Для теоретического прогноза выученные карточки считаются равномерно распределёнными по 119 карточкам; выученный ответ считается правильным, а невыученный — ошибкой. Отдельно отображается строгий прогноз по фактическим отметкам каждого варианта. Это математическая модель, а не гарантия результата.

Для непересекающихся диапазонов оценивание трактуется так: 0–5 ошибок — 5, 6–10 — 4, 11–15 — 3, 16 и более — ниже 3 (в исходных границах 5 и 10 пересекаются; они отнесены к более высокой оценке).

## Исторические уточнения

В ответах исправлены или оговорены отдельные спорные места из исходного материала. Например, личная встреча Петра I с Исааком Ньютоном не подтверждена документально; Патрик Гордон умер до Прутского похода; указ о престолонаследии 1722 года не был отменён Анной Иоанновной. Полный контекст и формулировки ответов находятся в \`data/variants.json\`.

## GitHub Pages

Сайт публикуется через GitHub Actions: **https://xaytol.github.io/history/**.

## Структура

- \`index.html\` — интерфейс.
- \`styles.css\` — адаптивное оформление и две цветовые темы.
- \`app.js\` — логика карточек, случайного порядка, самопроверки и сохранения прогресса.
- \`data/variants.json\` — четыре варианта теста с исходными вопросами и проверенными ответами.

Проект работает как статический сайт: сборка и сервер не нужны.
